# Backlog

Real defects and improvements a phase's verification turned up and judged **not
blocking** for that phase's gate. Each line: severity, file and symbol, what is
wrong, and — where it has one — the later plan task that should settle it.

Nothing here is a fix. A line leaves this file when a commit removes the defect
(record it under *Closed* with the task that closed it) or when
`DIVERGENCES.md` records it as accepted. Numbers are never reused, so a review
citing "phase 1, item 15" still points at the same thing.
