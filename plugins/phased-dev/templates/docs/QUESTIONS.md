# Questions

Every question about what to build, and its answer. Answers are the owner's.
Ids are never reused.

Rules:
- **Before the spec is confirmed:** every question tagged `spec` is answered.
- **Before a phase is prepared:** every question that affects it is answered.
- **During implementation:** a new question is recorded here at once. If it is
  *blocking* (the answer changes what the task builds), the task stops. If not,
  work proceeds on the stated assumption, and an answer that contradicts it
  becomes a new task.
