# Known divergences from {{AUTHORITY}}

Anything this program produces that the authority does not — or produces
differently — is argued for here, with a reason each. **We know we differ, and
why.** An empty list is the goal; an undocumented difference is a failure.

Each entry: **What** (the observable difference), **Why** (the reason, or the
authority's bug), **Measured** (how many records/fields on which data), and
**Held by** (the test that fails if the claim stops being true).

Every claim here is re-run at each phase gate. A false divergence note is the
same defect as a false doc comment.
